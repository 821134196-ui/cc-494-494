# 体检报告解读预约系统（演示）

体检中心出具报告后，用户可预约**线上或现场**解读、预先勾选想讨论的指标；报告只对
**本人 / 被授权医生 / 明确授权的家属**开放。纯 Python 标准库实现：SQLite 持久化、
PDF 存本地目录、邮件走模拟适配器，无任何第三方依赖。

> ⚠️ 本系统为功能演示环境，**所有人员、报告与检验数值均为虚构数据，不含任何真实病历**，
> 不得用于实际医疗决策。页面与 PDF 均带显著演示声明。

## 一键启动

```bash
./run.sh                 # 首次自动建库、生成 PDF 与演示数据，默认 http://127.0.0.1:8000
PORT=8011 ./run.sh       # 指定端口
./run.sh --reseed        # 重置演示数据后启动
python3 main.py --seed-only   # 只初始化数据不启动服务
```

需要 Python 3.10+（标准库即可，无需 pip 安装任何包）。

## 功能与确定处理规则

| 场景 | 确定处理 |
|---|---|
| **多人抢同一时段** | 单条条件 `UPDATE … WHERE booked_count<capacity` 在 `BEGIN IMMEDIATE` 事务内裁决；恰好 1 人锁定，其余得 409，无超卖、无读后写竞态 |
| **预约改期** | 同一事务内**先锁定新号、再释放原号**；任一步失败整体回滚，原号不会被错误释放 |
| **医生临时停诊** | 号源置 `canceled`、名额清零；该时段已预约**原子地**释放并转 `reschedule_pending`，入待改约队列并逐人发模拟邮件；已完成/已取消不受影响 |
| **开始前 2 小时** | 不允许自助改期/取消（提示联系体检中心） |
| **授权到期** | 可设绝对到期时间或天数（最长 365 天）；到期惰性失效 + 每请求清扫，链接随之作废 |
| **授权撤销** | 随时可撤销，**即刻生效**；该授权下所有下载链接立即置 `void`，并发模拟邮件通知 |
| **家属授权争议** | 患者本人或该家属可发起；争议期间授权**冻结**、链接作废；只能由**患者终局**“确认恢复”或“否认并撤销”，工作人员无权代决 |
| **下载链接** | 不透明令牌，绑定“人 + 版本 + 授权”；撤销/到期/链接 TTL（48h）/**旧版本被更正替代**统一返回 **410 Gone** 并立即作废，不复活 |
| **报告更正** | 生成不可变新版本（`correction`，`supersedes` 指向前版）与新 PDF；旧版仅本人可追溯留档、停止下载；旧链接全部失效；患者收邮件 |
| **版本引用** | 预约与会诊记录固化 `report_version_id`；事后更正**不改写**历史引用，解读始终对得上当时版本 |
| **会诊记录未签字** | 初始 `draft`（待签字），须医生填齐总体意见+建议并输入签名口令才定稿；未签字对患者明确标注“待签字”，不作正式结论；签字后只读，修改需**作废留痕+同预约重开** |
| **访问控制** | 仅本人 / 有效授权医生 / 有效授权家属；工作人员只能做版本管理不能浏览个人内容；每次允许/拒绝写 `access_logs` |

## 解读页与移动端

- **指标趋势与医生备注并置**：左侧历年折线（参考范围色带、超出范围点警示并标 ↑/↓），
  右侧该指标的医生备注；异常指标均显示**数值 + 单位 + 参考范围**。
- **移动端首屏顺序**：下一次预约时间（线上/现场）→ 待改约告警 → 授权状态 → 预约列表。
- 配色严格使用**医疗白 `#ffffff` / 石墨灰 `#2f3638`、`#606a6e` / 克制的青 `#147d80`**，
  异常用克制的琥珀灰 + 图标 + 文字（不单靠颜色）。正文对比度 12.3:1。
- PDF 为自写生成器（标准库 zlib），内嵌拉丁与中日韩字体、附 ToUnicode，
  可复制检索；**更正件首页显著标注更正原因**。

## 测试

```bash
python3 -m unittest discover -s tests -p "test_*.py"   # 28 项，约 2 秒
```

覆盖：
- `test_booking.py`：**10 线程并发抢同一号源恰 1 胜**、2 容量恰 2 胜、两人并发改期到同一号源
  （败者原号不被释放）、停诊转待改约、2 小时限制；
- `test_access_versions.py`：**授权撤销后链接立即失效**、到期失效、链接 TTL、争议冻结/患者终局、
  **更正后旧链接 410**、版本引用不被改写、越权更正被拒；
- `test_interpretation.py`：未签字为草稿、错误口令/内容不全拒签、签字定稿、作废重开、
  PDF 哈希稳定、多年趋势归组与版本溯源。

## 主要代码结构

```
main.py                    单命令入口（自动播种 + HTTP 服务）
scripts/seed.py            虚构演示数据（含更正报告样例）
healthcheck/
  db.py                    SQLite schema / WAL / BEGIN IMMEDIATE / 嵌套事务(SAVEPOINT)
  booking.py               号源日历、抢号、改期、停诊、待改约队列
  access.py                授权判定、下载链接签发/校验、访问日志
  consents.py              授予/撤销/到期/家属争议
  versions.py              报告版本、更正件、跨年度趋势
  interpretation.py        解读记录、指标备注、电子签字规则
  reports.py / pdfkit.py   报告 PDF 渲染 / 最小中文 PDF 生成器
  charts.py                趋势内联 SVG
  mailer.py                模拟邮件适配器（写入 SQLite，页面“模拟邮箱”可查）
  web/                     HTTP 服务与患者/医生/家属/体检中心页面
tests/                     并发、授权撤销、旧链接失效、版本引用测试
```
