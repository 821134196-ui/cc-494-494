# 体检报告解读预约系统（演示）

体检中心出具报告后，受检人在线预约医生解读：选择**线上/现场**时段、预先勾选想讨论的
指标；报告只对**本人、被授权医生、明确授权的家属**开放。零第三方依赖，仅使用 Python
标准库（SQLite + http.server），PDF 由内置的最小生成器输出，邮件由模拟适配器落库。

> 所有受检人、医生、家属与检验数值均为**虚构合成数据**，不包含任何真实病历；
> 每份 PDF 页脚均印有「演示数据·无真实病历」声明。

## 单命令启动

```bash
./run.sh              # 首次运行自动建库、生成演示数据与 PDF，然后启动
# 或：python3 -m app.main
```

打开 <http://127.0.0.1:8000/> ，在登录页选择演示身份进入。

```bash
./run.sh --reset      # 清空数据，重新生成（含更正报告样例）
./run.sh --test       # 运行全部测试（39 个）
HC_PORT=9000 ./run.sh # 自定义端口（另有 HC_HOST/HC_DATA_DIR/HC_DB_PATH/HC_PDF_DIR）
```

## 功能与确定处理规则

- **号源日历**：30 分钟粒度，线上视频/现场面诊区分；停诊置灰、约满有明确提示。
- **抢同一时段（并发）**：名额变动是 `BEGIN IMMEDIATE` 事务内的单条条件 UPDATE
  （`WHERE booked < capacity`）。N 人并发抢一个号 → 恰好 1 人成功，其余得到明确
  409「已约满」，**绝不超卖**（见 `test_scheduling.SlotRaceTests`，10 线程实测）。
- **改期**：同一事务内**先锁新号源、再释放原号源**；新号源抢不到则整体回滚，
  原预约不受影响（不会两头落空）。旧单置 `rescheduled`，新单 `booked` 并保留
  讨论指标与报告版本引用。
- **医生临时停诊**：区间号源置 `suspended`，受影响预约**自动转「待改约」队列**、
  释放名额，并经模拟邮件通知患者；患者在概览首屏看到红色待改约横幅，一键改约。
- **报告版本/更正**：版本号严格递增，更正件必须填写更正原因、`supersedes` 指向旧版；
  旧版本 PDF 与 SHA-256 校验和固定保留、不可变。**预约与解读记录引用的具体版本不随
  更正漂移**；解读页对引用了旧版本的预约显示更正横幅并链接到更正件。
- **授权管理**：可向医生/家属授予，可设到期天数，可随时撤销；到期惰性失效并有
  定时扫描兜底；`active/revoked/expired/disputed` 四态。
- **授权撤销 → 下载链接立即失效**：撤销在同一事务把名下所有 `valid` 链接置
  `revoked`；旧链接再次访问返回 403「该链接因授权撤销已立即失效」，无需等待过期。
- **家属授权争议**：本人或家属可发起，发起即冻结（失败关闭，暂停全部访问、链接失效）；
  **只能由本人裁决**恢复或正式撤销，结果确定。
- **会诊记录未签字**：新建即为草稿，页面明确标注「未签字·不具备正式效力」，
  预约不会置为完成；签字（SHA-256 留痕）后才成为正式结论；已签字内容再修改会
  自动转为「修改待重签」、预约退回已预约，必须重新签字。
- **访问控制（失败关闭）**：本人/有效授权医生/有效授权家属之外的任何访问一律 403
  并写入 `access_logs`（含被拒绝的尝试）。PDF 下载有路径穿越防护。
- **解读页**：指标趋势 SVG 迷你图（参考范围带 + 折线，异常点暗红且同时给出 ↑/↓、
  数值与参考范围，不仅靠颜色）与医生按指标备注左右并置。
- **移动端**：概览首屏第一张卡片即「最近预约时间 + 待改约」，紧随「授权状态」；
  单列布局。整页配色为医疗白 `#ffffff`、石墨灰 `#2b2f33`、克制青 `#0e8a8c`，
  异常使用克制暗红 `#b3261e`。

## 数据与文件

```
data/
├── healthcheck.db      # SQLite：用户/报告版本/指标/号源/预约/授权/下载链接/解读记录/访问日志/模拟邮件
└── pdfs/               # 本地 PDF，每版本一个文件（TJ2026-0001_v1.pdf / _v2.pdf …）
```

- 邮件不真实发送，写入 `mail_outbox`，各身份下的「模拟邮件」页可查看。
- PDF 中文使用 PDF 标准 CID 字体 `STSong-Light / UniGB-UCS2-H`，无需外部字体文件；
  Chrome、Edge、Acrobat、WPS 等可直接打开。

## 代码结构

```
app/
  db.py                      # SQLite 连接、立即写事务、全部表结构
  errors.py                  # 404/403/409/422 领域错误
  audit.py                   # 访问日志
  mailer.py                  # 模拟邮件适配器
  pdfgen.py                  # 零依赖 PDF 生成器 + 报告排版
  templates.py               # 页面/CSS/配色令牌/SVG 趋势图
  web.py                     # http.server 路由（患者/医生/家属）
  seed.py                    # 虚构演示数据（含更正样例）
  services/
    scheduling.py            # 号源/抢号/改期/停诊/待改约队列
    reports.py               # 报告版本、更正、趋势、受控查看
    access_control.py        # 有效授权判定（失败关闭）
    authorizations.py        # 授予/到期/撤销/争议/下载链接
    interpretations.py       # 解读备注、签字、重签规则
tests/                       # 39 个 unittest
```
